# Changelog — Vaultsh

## 🚀 [1.0.0-beta.1] — 2026-10-27

### ✨ Добавлено
- Создание/восстановление кошельков Bitcoin, Ethereum Mainnet и Solana по английской BIP-39 фразе с зашифрованными записями BTC/ETH/SOL.
- Локальная подпись и отправка P2WPKH BTC, нативного ETH (legacy EIP-155) и нативного SOL после просмотра и точного текстового подтверждения.
- Monero через официальный локальный `monero-wallet-rpc`: подготовка транзакции без relay, relay только после подтверждения.
- QR/PNG для распознаваемых публичных адресов BTC/EVM/XMR/SOL.
- Команды и тесты отправки, проверки суммы/адреса/Mainnet и relay metadata XMR.

### 🔄 Изменено
- Версия пакета `1.0.0b1` (название релиза `1.0.0-beta.1`). Документация и интерфейс обновлены на EN/PL/RU.

### 🧪 Тесты
- Локально: **194 passed, 7 skipped, покрытие 53%**.
- Пропуски: Textual (1), embit (4), eth-utils (1), eth-account (1). Реальные RPC/Esplora не вызывались, реальные транзакции не отправлялись.

### 🛡️ Ограничения безопасности
- **Не используйте BTC send с реальными средствами:** UTXO ищутся только для первого receive-адреса; change `/1/0` Vaultsh пока не обнаруживает.
- ETH send — только нативный ETH Mainnet legacy. SOL send — только нативный SOL. Monero использует внешний процесс `monero-wallet-rpc`, который должен работать локально и быть корректно настроен.
- Нет аудита, транспорта Tor, multisig, hardware wallet или тестирования реальных broadcast.
