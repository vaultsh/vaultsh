## Базовый уровень: 0.6.0

- [x] CLI Typer/Rich, команды и конфигурация TOML без секретов.
- [x] Scrypt и AES-256-GCM для локального шифрованного хранилища.
- [x] Чтение схемы хранилища v1 и записи Bitcoin-кошельков v2.
- [x] Зашифрованное резервное копирование и восстановление.
- [x] Ограниченное офлайн-создание/восстановление Bitcoin Mainnet BIP-39/BIP-84.
- [x] Чтение баланса одного BTC-адреса и первой страницы истории.
- [x] Чтение нативного баланса пяти EVM-профилей с проверкой chain ID.
- [x] Явные endpoint, двойное сетевое разрешение, тайм-ауты, лимиты и блокировка редиректов.
- [x] Локальные тесты с поддельными ответами и документация на английском.
- [x] README и документация на польском и русском; частичная локализация панели CLI.
- [ ] Подтверждённые результаты CI на Windows/Linux.
- [ ] Все тестовые векторы запускаются с полным набором зависимостей.
- [ ] Независимый аудит безопасности и проверка зависимостей.

## Этап 1 — основа проекта

- [x] Структура Python-пакета и CLI Typer/Rich.
- [x] Базовые тесты и конфигурация инструментов.
- [x] Шаблон TOML и команды проверки.
- [x] Модель угроз, правила участия и индекс документации.
- [ ] Регулярный CI на Windows/Linux с подтверждёнными результатами.
- [ ] Аудит зависимостей/лицензий и происхождения релизов.

## Этап 2 — безопасное локальное хранение

- [x] Версионированный документ внутри шифрованного контейнера.
- [x] Проверка параметров Scrypt, AES-256-GCM, атомарная запись и тесты резервного копирования.
- [x] Ограниченные записи Bitcoin с материалом восстановления в шифрованной полезной нагрузке.
- [ ] Независимый обзор формата, работы с секретами и восстановления.
- [ ] Стратегия миграции/экспорта до добавления новых семейств кошельков.

## Этап 3 — блокчейн-интеграция

- [x] Первый офлайн-сценарий Bitcoin BIP-39/BIP-84.
- [x] Баланс и история одного BTC-адреса.
- [x] Нативный баланс пяти EVM-профилей.
- [ ] Поиск адресов Bitcoin, gap limit, адреса сдачи, полный баланс и история кошелька.
- [ ] Создание/восстановление EVM-кошельков и безопасное хранение ключей.
- [ ] ERC-20 и история транзакций EVM.
- [ ] Просмотр транзакции, расчёт комиссий/gas, построение и офлайн-подписание.
- [ ] Независимая проверка до использования реальных средств.

## Этап 5 — подготовка стабильного релиза

- [ ] Тесты Windows, Linux и Android/Termux.

- [ ] Аудит зависимостей, лицензий и цепочки поставок.

## Требования перед реальными средствами

Независимый аудит, полный набор векторов, проверенное восстановление резервной копии, проверка секретов и подписания, CI на целевых системах и процесс реагирования на инциденты.
