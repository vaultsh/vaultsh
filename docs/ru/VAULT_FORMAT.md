# Формат зашифрованного хранилища

**🌐 Язык:** [English](../VAULT_FORMAT.md) · [Polski](../pl/VAULT_FORMAT.md) · [Русский](VAULT_FORMAT.md) · [README](../../README.ru.md)

## Уровни файла

Файл содержит заголовок шифрования и зашифрованный JSON-документ. Содержимое недоступно без derivation ключа из пароля и успешной аутентификации.

## Криптографический конверт

- Магическая метка: `VSHV`; версия конверта: `1`.
- Вывод ключа из пароля: Scrypt; параметры по умолчанию `N = 2**15`, `r = 8`, `p = 1`.
- Salt: 16 случайных байт из ОС.
- Nonce AES-GCM: 12 байт; ключ AES-256: 32 байта; tag аутентификации обнаруживает изменение содержимого.
- Заголовок аутентифицируется как дополнительные данные.
- Перед затратным вычислением проверяются границы параметров: `N` от `2**14` до `2**16` и степень двойки, `r` от 1 до 8, `p` от 1 до 4.
- Размер файла ограничен 64 MiB.

## Внутренний документ

Общие поля: `schema = vaultsh.vault`, поддерживаемый `schema_version`, канонический UUID `vault_id`, непустая метка до 80 символов без управляющих символов, `created_at` ISO 8601 с часовым поясом и список `wallets`.

### Схема v1

Содержит метаданные хранилища и пустой список кошельков; наличие такой схемы само по себе не означает хранение секретов.

### Схема v2

Запись Bitcoin включает `wallet_id`, `label`, `network = bitcoin-mainnet`, первый адрес Native SegWit P2WPKH, путь `m/84'/0'/0'/0/0`, время создания и английскую фразу BIP-39 из 12 или 24 слов.

## EVM и миграция

Эта схема пока не хранит ключи EVM; EVM-адаптер работает только для чтения. Старые документы v1 остаются читаемыми. Обычная проверка хранилища не мигрирует схему; добавление Bitcoin-кошелька атомарно заменяет зашифрованный документ на v2.

## Секреты и резервные копии

Обычный список кошельков не выводит фразу. Для показа требуется явное подтверждение и разблокировка, однако терминал может записываться. Резервная копия — копия зашифрованного файла; её содержимое защищено, но владелец файла может пытаться подбирать пароль офлайн. Защищайте пароль и фразу отдельно.

## Совместимость

Формат находится на стадии pre-alpha и не проходил независимый аудит. Поведение может измениться до стабильного выпуска; перед обновлением сделайте зашифрованную копию и проверьте восстановление.
