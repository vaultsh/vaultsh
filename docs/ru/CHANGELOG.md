## 🚀 [0.6.0] — 2026-10-27

- Добавлено получение первой страницы истории одного Bitcoin-адреса через Esplora (до 25 записей).
- Добавлено чтение нативных балансов Ethereum, Polygon PoS, Arbitrum One, Optimism и Base с проверкой `chainId`.
- Добавлена проверка EVM-адресов и checksum EIP-55 для смешанного регистра.
- Добавлены лимиты HTTP-ответов, тайм-ауты, блокирование редиректов и сетевые тесты на заглушках.
- EVM-ключи/кошельки, ERC-20, Monero, подписание/отправка транзакций и транспорт Tor не реализованы.

## 🚀 [0.4.5] — 2026-10-27

- Добавлено чтение баланса одного Bitcoin-адреса после явного разрешения сети.
- Добавлены HTTPS-правила для удалённых endpoint, лимиты ответа и проверка статистики баланса.

## 🚀 [0.3.0] — 2026-10-27

- Добавлено ограниченное офлайн-создание/восстановление Bitcoin Mainnet BIP-39/BIP-84 и записи кошельков в схеме хранилища v2.
- Добавлен вывод публичных метаданных без фраз восстановления.

## 🚀 [0.2.0] — 2026-10-27

- Добавлены команды создания/проверки зашифрованного хранилища, резервного копирования/восстановления и создания/проверки TOML-конфигурации.

## 🚀 [0.1.0] — 2026-10-27

- Добавлены начальная структура Python-пакета, CLI Typer/Rich, настройки, примитивы шифрования, резервные копии и базовые тесты.
