## Статус проекта

**Vaultsh 0.6.0 — предварительная версия pre-alpha без независимого аудита. Не используйте её для хранения или отправки реальных средств.** Проект объединяет локальные зашифрованные хранилища и резервные копии с офлайн-созданием/восстановлением Bitcoin Mainnet-кошелька и сетевыми запросами только для чтения, которые требуют явного разрешения.

Для Bitcoin доступен ограниченный сценарий BIP-39/BIP-84, баланс одного адреса и первая страница истории транзакций через выбранный пользователем endpoint Esplora. В пяти сетях EVM — Ethereum, Polygon PoS, Arbitrum One, Optimism и Base — доступно только чтение нативного баланса через выбранный JSON-RPC endpoint. Управление EVM-ключами, токены ERC-20, создание, подписание и отправка транзакций не реализованы. Monero не реализован.

Проект написан на Python. Целевые платформы — Windows 10/11, Linux и Android через Termux, однако каждую платформу необходимо проверять отдельно.

## Что нового в 0.6.0

- Получение первой страницы истории транзакций одного адреса Bitcoin через выбранный endpoint Esplora (не более 25 записей).
- Чтение нативного баланса Ethereum (chain ID 1), Polygon PoS (137), Arbitrum One (42161), Optimism (10) и Base (8453). Перед запросом баланса проверяется `eth_chainId`.
- Проверка формата EVM-адреса и контрольной суммы EIP-55 для адресов со смешанным регистром.
- Сетевые запросы по умолчанию отключены. Требуются одновременно `network_requests_enabled = true` в TOML и флаг `--allow-network`.
- Endpoint указывается явно. Для удалённых endpoint обязателен HTTPS; HTTP разрешён только для localhost/loopback. Перенаправления и автоматическое использование proxy из переменных окружения отключены.

## Результаты тестов

Последний локальный запуск 27.10.2026 завершился результатом: **144 теста пройдены, 4 пропущены, покрытие строк — 82%**. Команда: `pytest --cov=vaultsh --cov-report=term-missing -q`, Python 3.13.5. Четыре теста пропущены, потому что в среде отсутствовали зависимости `embit` и `eth-utils`. Сетевые тесты используют заглушки; запросы к публичным API не выполнялись. Эти результаты не являются сертификацией безопасности. Подробности: [отчёт о тестах](docs/ru/TEST_RESULTS.md).

## Язык интерфейса

Стартовая панель и основные информационные экраны поддерживают английский, польский и русский языки. Укажите язык перед командой: `vaultsh --lang ru` или `vaultsh --lang pl about`. Подробная справка по командам, некоторые запросы ввода и низкоуровневые сообщения об ошибках в этой версии пока остаются на английском.

## Установка

Требуется Python 3.12 или новее. В корне репозитория выполните:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Linux/macOS/Termux: source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

`embit` предоставляет примитивы BIP-39/BIP-32/BIP-84, а `eth-utils` и `eth-hash[pycryptodome]` используются для проверки контрольной суммы EIP-55. Зависимости следует устанавливать в доверенной среде и проверять перед production-использованием.

## Быстрый старт

Создайте зашифрованное хранилище. Пароль вводится скрыто и должен содержать не менее 12 символов:

```bash
vaultsh vault init ./main.vault --label "Основное хранилище"
vaultsh wallet create --vault ./main.vault --label "Bitcoin Main"
vaultsh wallet list --vault ./main.vault
```

При создании кошелька фраза восстановления отображается для сохранения офлайн и также хранится внутри аутентифицированного зашифрованного содержимого хранилища. Любой, кто знает фразу, может управлять кошельком. До использования реальных средств нужны аудит и значительно более широкие тесты.

## Сетевые запросы и конфиденциальность

Пример чтения баланса EVM (замените адрес и endpoint собственными значениями):

```bash
vaultsh evm balance 0xYOUR_ADDRESS --chain polygon --endpoint https://YOUR-RPC --config ./vaultsh.toml --allow-network
```

Выбранный endpoint узнает проверяемый адрес и метаданные соединения. Tor не реализован. Если `tor_enabled = true`, сетевые команды откажутся от прямого подключения. Поставщик по умолчанию не выбирается.
