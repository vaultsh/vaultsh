# Результаты тестов — Vaultsh 0.6.0 (текущая рабочая версия)

**🌐 Язык:** [English](../TEST_RESULTS.md) · [Polski](../pl/TEST_RESULTS.md) · [Русский](TEST_RESULTS.md) · [README](../../README.ru.md)

## Локальная среда

- ОС: Linux-контейнер.
- Python: `3.13.5`.
- pytest: `9.0.2`.
- pytest-cov: `7.0.0`.
- Команда: `pytest --cov=vaultsh --cov-report=term-missing -q`.
- Публичные RPC/Esplora запросы не выполнялись; сетевые клиенты проверялись на поддельных ответах.

## Результат

**144 теста пройдены, 4 пропущены. Покрытие строк — 82%.**

| Метрика | Результат |
|---|---:|
| Пройдено тестов | 144 |
| Пропущено | 4 |
| Измерено инструкций | 1400 |
| Покрыто инструкций | 1141 |
| Не покрыто инструкций | 259 |
| Общее покрытие | 82% |

Пять UI-тестов проверяют польскую стартовую панель и обзор сетей, русские экраны `about` и `privacy`, а также отклонение неподдерживаемого языка. Другие тесты охватывают шифрование, хранилище, настройки, CLI, сетевую политику, Bitcoin и EVM-профили.

## Почему тесты пропущены

- Три теста derivation/восстановления Bitcoin требуют `embit`, отсутствовавший в локальной среде.
- Один тест checksum EIP-55 для смешанного регистра требует `eth-utils`, также отсутствовавший локально.

## Важные пробелы проверки

Ruff, mypy и сборка пакета не запускались, если инструменты отсутствовали. Не подтверждены hosted CI на Windows/Linux, совместимость Termux, реальные сетевые endpoints и независимый аудит. Тесты и coverage не являются сертификатом безопасности.

## Повторение результата

Установите зависимости в доверенной среде через `python -m pip install -e ".[dev]"`, затем запустите `pytest --cov=vaultsh --cov-report=term-missing -q`. При наличии всех зависимостей тесты, которые сейчас пропускаются, должны выполниться.
