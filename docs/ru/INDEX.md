## Функции в 0.6.0

- Локальные зашифрованные хранилища и резервные копии.
- Ограниченное офлайн-создание/восстановление Bitcoin Mainnet BIP-39/BIP-84.
- Чтение баланса и первой страницы истории одного BTC-адреса через явно выбранный Esplora endpoint.
- Чтение нативного баланса через JSON-RPC для Ethereum, Polygon PoS, Arbitrum One, Optimism и Base.
- Каждый сетевой запрос требует `network_requests_enabled = true` и `--allow-network`.

Ключи/кошельки EVM, ERC-20, Monero, история EVM, поиск всех адресов, подписание/отправка транзакций и настоящий транспорт Tor не реализованы.
